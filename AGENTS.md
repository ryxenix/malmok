# Repository working agreements

- After completing and verifying a requested change, commit the task's changes.
  Preserve unrelated work and do not include it in the commit.
- Do not push unless the user explicitly requests it.
- `ryxenix/malmok` is public, and its documentation is published at https://malmok.dev/.
  The user has completed and authorized this public release.
- Keep `ryxenix/malmok-internal` private. Do not copy internal documents or sensitive
  information into this public repository.
- Do not change repository visibility or trigger further deployments without
  explicit user authorization.
